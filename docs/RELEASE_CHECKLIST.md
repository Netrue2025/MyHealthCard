# Release checklist

- [ ] Written intended use and Nigerian regulatory classification decision
- [ ] DPIA, lawful basis, sensitive-data conditions, processors and transfer assessment
- [ ] Approved privacy notice, terms, provider agreements and retention schedule
- [ ] Named clinical review of wording, hazards, ranges and critical flag behavior
- [ ] Documented practitioner/facility verification procedure and evidence sources
- [ ] Production MFA, email recovery, private object storage, scanner and job adapters
- [ ] Independent security review and closed/accepted findings
- [ ] Integration and browser acceptance suite against production-like services
- [ ] Encrypted database/object backups and witnessed restore evidence
- [ ] Incident, support, correction, deletion and exceptional access owners
- [ ] Synthetic credentials absent; public buckets absent; feature flags match approvals
- [ ] Named go/no-go decision with owner and date
